# Tiny Portfolio Roadmap

## v0.1 — Plugin Foundation

- Product contract
- Plugin manifest
- Privacy model
- Portable portfolio schema
- Deterministic accounting engine
- HOLD, WAIT, and REVIEW classification engine
- Automated tests

## v0.2 — Guided Check-In

- New-user onboarding
- Portfolio rule setup
- Prompt-based updates
- Proposed-update confirmation
- Standard Tiny Portfolio Briefing

## v0.3 — Screenshot Assist

- Screenshot safety guidance
- Visible-value extraction workflow
- Confidence and uncertainty handling
- Hybrid follow-up questions
- Explicit confirmation requirement

## v0.4 — Public Alpha

- Fresh-conversation testing
- Example portfolio
- Complete public documentation
- Logo and product screenshots
- Privacy and support pages
- Plugin submission package

## Future consideration

If adoption justifies promotion beyond Meranor Labs, evaluate persistent storage, optional integrations, richer interfaces, and dedicated hosted services without weakening the privacy-first product boundary.
