# Security and Privacy

Tiny Portfolio is designed to minimize access to sensitive financial information.

## Never share

Do not submit any of the following through issues, pull requests, examples, screenshots, fixtures, or logs:

- passwords or authentication codes;
- seed phrases or private keys;
- complete account numbers;
- Social Security numbers or tax identifiers;
- exchange API secrets;
- private portfolio exports containing identifying information;
- real screenshots that have not been intentionally sanitized.

## Reporting a vulnerability

Please avoid publishing exploitable details or personal information in a public issue. Contact Meranor Systems privately through the support or security contact published for the project once that channel is established.

Until then, public issues should contain only sanitized reproduction steps and synthetic data.

## Scope boundary

Tiny Portfolio does not execute trades and must not request credentials that would enable trading or account access. Any change that weakens this boundary requires explicit public review before merge.
