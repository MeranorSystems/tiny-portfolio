# Tiny Portfolio Brand Assets

Tiny Portfolio uses PNG assets for repository and plugin branding.

## Approved public-safe assets

The following files are the approved Phase 0 public set:

- `tiny-portfolio-hero.png` — wide README/project hero
- `tiny-portfolio-update-styles.png` — Guided / Screenshot / Hybrid explainer
- `tiny-portfolio-logo-mark.png` — transparent TP mark
- `tiny-portfolio-wordmark.png` — horizontal Tiny Portfolio wordmark
- `tiny-portfolio-icon.png` — rounded-square plugin/app icon

These assets should be used only where their accompanying copy accurately reflects implemented product behavior.

## Public-claim rule

Do not publish concept art that implies unimplemented capabilities such as:

- live portfolio pricing;
- real-time market signals;
- direct exchange/brokerage connectivity;
- on-device-only storage;
- stronger security guarantees than the product actually provides.

Source and exploratory brand concepts are retained in the project planning workspace rather than treated as production claims.

## Format rule

Core repository and plugin branding should use PNG assets for maximum compatibility.
